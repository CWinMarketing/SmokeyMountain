# Assets

Drop exported Wix images here (logos, driver/car photos, sponsor logos) and update the
`.media-box` placeholders in the HTML files to real `<img>` tags pointing at these files.

To export from Wix: Dashboard → Media Manager → select all → Download. For the three team
logos (Smokey Mountain Racing, Blue Ridge Racing, Appalachian Mountain Autosport), use
original source files if available instead of Wix's web-compressed copies.
